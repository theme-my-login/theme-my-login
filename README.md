# Theme My Login

Creates an alternate login, registration, and password recovery experience within your WordPress theme, so users never see the default `wp-login.php` page.

- Plugin homepage: https://thememylogin.com
- WordPress.org listing: https://wordpress.org/plugins/theme-my-login/
- Extensions catalog: https://thememylogin.com/extensions

## Requirements

- PHP >= 7.4
- WordPress >= 5.4

## Repo layout

```
src/                 Plugin source (PHP, assets). This is what ships, minus the build step.
  theme-my-login.php  Extension-facing bootstrap (class/function definitions)
  includes/           Core classes: actions, forms, extensions, hooks, options
  admin/               Admin screens (extensions page, settings)
  assets/              Frontend styles/scripts (uncompiled)
  readme.txt           WordPress.org listing content + changelog (svn trunk source of truth)
build/                Generated by `npm run build`. Not committed; this is the deployable plugin.
theme-my-login.php    Root loader: includes build/ if present, else src/ (set TML_LOAD_SOURCE to force src/)
tests/                PHPUnit test suite
bin/draft-changelog.php  Drafts src/readme.txt changelog entries from Conventional Commits, used by CI on release PRs
```

## Development setup

```
npm install
composer install
```

### Build

```
npm run build   # compile src/ into build/
npm run watch   # rebuild on change
npm run clean   # remove build/
```

The root `theme-my-login.php` loads `build/theme-my-login.php` when present, so run a build (or define `TML_LOAD_SOURCE`) to see changes reflected when the plugin loads normally. PHPUnit always loads from `src/` directly regardless (see `tests/bootstrap.php`).

### Test

```
composer test          # phpunit
composer test:strict   # phpunit with WP_TESTS_STRICT_DEPRECATIONS + --fail-on-risky
```

Requires a MySQL database reachable per `wp-phpunit`'s usual env vars; see `tests/wp-tests-config.php`. `tests/multisite/` runs separately via `tests/phpunit/multisite.xml`.

### Lint

```
composer lint       # phpcs (WordPress Coding Standards)
composer lint:fix    # phpcbf
```
